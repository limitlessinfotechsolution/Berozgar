# Berozgar Website — Modern, Premium & Professional Design Plan

The website should feel like a **premium creative-production brand**, not a generic printing website.

The design direction should combine:

**Premium visual identity + minimal UI + strong typography + high-quality product photography + smooth interactions + strong conversion UX.**

---

## 1. Brand Positioning

### Desired impression

When someone opens Berozgar, they should immediately feel:

* Premium
* Trustworthy
* Modern
* Creative
* Professional
* Reliable
* Easy to work with

### Avoid

* Overcrowded layouts
* Too many colors
* Cheap-looking gradients
* Excessive animations
* Generic stock imagery
* Old-fashioned ecommerce layouts
* Too many buttons
* Complicated navigation

# 3. Color Strategy

Use a **mostly monochrome base**.

### Primary

Black / near-black

### Background

Warm white / off-white

### Secondary

Light grey

### Accent

One strong Berozgar brand accent color.

The accent should be used sparingly for:

* CTA buttons
* Important highlights
* Active states
* Small visual details

This keeps the site premium.

---

# 4. Typography

Use a premium modern font system.

### Option A

**Manrope**

### Option B

**Inter**

### Option C

**Plus Jakarta Sans**

Recommended:

**Manrope + Inter**

Large display headings should be bold and confident.

Example:

> **WE TURN IDEAS
> INTO SOMETHING
> REAL.**

Short headlines are better than large paragraphs.

# 25. Animation System

Use animation as a premium detail.

### Page entrance

Subtle fade + upward movement.

### Images

Slow reveal.

### Hover

Small scale / movement.

### Buttons

Arrow movement.

### Scroll

Subtle parallax for selected sections.

### Avoid

* Constant floating elements
* Excessive particle effects
* Huge loading animations
* Distracting transitions

# 27. Responsive Breakpoints

Design for:

**Mobile**
320–767px

**Tablet**
768–1023px

**Desktop**
1024–1439px

**Large Desktop**
1440px+

The 1440px version should be the primary design reference.

---

# 28. Performance

Premium design should still be fast.

Prioritize:

* WebP/AVIF images
* Lazy loading
* Optimized fonts
* Minimal JavaScript
* Lightweight animations
* CDN
* Responsive image sizes

Target:

**Fast first load + smooth scrolling + excellent mobile performance.**

* Internal links
* Product/schema markup where applicable

# 30. Final Design Direction

The final Berozgar website should feel closer to:

**Premium creative studio + modern ecommerce + professional production company**

rather than:

**Traditional printing shop website.**

### The visual formula:

**70% Clean / Minimal**

**20% Product & Brand Photography**

**10% Accent / Motion**

And the overall experience should communicate:

> **Berozgar doesn't simply print products.
> Berozgar turns ideas into finished brands, products and experiences.**
